# E-Commerce Project

Dự án thương mại điện tử bao gồm Frontend và Backend:

## Cấu trúc thư mục

- `ecommerce-store/`: Giao diện cửa hàng (Next.js, TypeScript, Tailwind/CSS)
- `medusa-store/`: Hệ thống Backend & API (MedusaJS v2, PostgreSQL, Redis)

## Hướng dẫn cài đặt & chạy

### 1. Backend (`medusa-store`)
```bash
cd medusa-store
yarn install
yarn dev
```

### 2. Frontend (`ecommerce-store`)
```bash
cd ecommerce-store
npm install
npm run dev
```
Mở trình duyệt truy cập: [http://localhost:3000](http://localhost:3000)
